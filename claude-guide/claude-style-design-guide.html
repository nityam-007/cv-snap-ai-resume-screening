Deck example

A section-break slide, inverted to ink — used once or twice per deck, not every slide.

One idea per slide.

Section breaks invert the palette sparingly to create rhythm across a long deck, without turning the whole system dark.

Built as a reference system inspired by Claude / Anthropic's visual language. Color values reflect Anthropic's published brand palette; typography and finer component details are inferred to match the product's overall feel. Adjust freely for your deck's needs.
